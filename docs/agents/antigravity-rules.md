# Antigravity Operational Rules — manufacturing-ai-week4

1. **실시간 검증 필수**: 코드나 문서 완료 보고 시 파일 경로, SHA 해시, 실행 로그 등 concrete 증거를 제시한다.
2. **설계 우선 원칙**: 사전 승인(Reviewer PASS) 전 임의의 소스코드 파일 이동(`git mv`)을 일절 금지한다.
3. **문서 무결성**: 기존 파일 내용의 임의 삭제를 금지하고, 표준 프론트매터 및 RAG 인덱스를 완벽히 동기화한다.
