# Antigravity Role Definition — manufacturing-ai-week4

## 1. 역할 정의 (Role Overview)
Antigravity는 풀스택 프론트엔드 UI/UX 구현, 대시보드 렌더링, 아키텍처 문서화 및 브라우저 기반 검증을 전담하는 작업 세션(Work Session)입니다.

## 2. 주요 책임 (Responsibilities)
- UI 컴포넌트, 반응형 스타일시트, 대시보드 뷰 개발.
- 표준 아키텍처 문서(ARCHITECTURE.md, RULES.md, ASSET-MAP.md 등) 작성 및 RAG 매니페스트 관리.
- 브라우저 렌더링 및 엔드투엔드 검증 증거 생성.

## 3. 작업 규칙
- Strict Mode 기준(90점 이상)을 충족하는 실시간 concrete 증거를 남기며 완료를 보고한다.
