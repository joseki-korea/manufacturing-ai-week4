# Claude Operational Rules — manufacturing-ai-week4

1. **지시 준수**: 상위 기획 문서 및 요구사항에 근거하여 명확한 디스패치를 수행한다.
2. **코드 수정 배제**: 비즈니스 소스코드를 직접 커밋하지 않으며, 감수 및 판정 역할에 집중한다.
3. **엄격한 게이트 검수**: 3자 상호 검토 점수 90점 이상 달성 여부를 객관적으로 확인한다.
