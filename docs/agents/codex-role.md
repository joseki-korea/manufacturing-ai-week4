# Codex Terra Role Definition — manufacturing-ai-week4

## 1. 역할 정의 (Role Overview)
Codex Terra는 핵심 비즈니스 로직 및 백엔드/알고리즘 구현을 담당하는 주력 작업 세션(Work Session)입니다.

## 2. 주요 책임 (Responsibilities)
- 코어 계산 알고리즘, 데이터 처리 파이프라인 및 백엔드 로직 구현.
- 단위 테스트 작성 및 코드 안정성 검증.
- 단독 커밋 원칙을 준수하여 추적 가능한 변경 기록 유지.

## 3. 작업 규칙
- 기존 기능을 파괴하지 않으며, 변경 전후 빌드/테스트를 반드시 통과한다.
