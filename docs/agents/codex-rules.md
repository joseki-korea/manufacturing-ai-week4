# Codex Terra Operational Rules — manufacturing-ai-week4

1. **실행 검증 필수**: 코드 변경 후 반드시 빌드 및 테스트 명령어를 실행하여 통과 여부를 입증한다.
2. **단독 커밋**: 논리적 작업 단위별로 명확한 커밋 메시지와 함께 단독 커밋을 수행한다.
3. **추측 답변 금지**: 실제 코드베이스와 파일 상태를 확인한 객관적 사실만을 기반으로 작업한다.
